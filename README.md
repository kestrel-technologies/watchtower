# Watchtower

Collectors and source configuration for Watchtower, Kestrel's central event monitoring platform.

- Sources: `config/sources.yaml`
- Collectors: `watchtower/collectors/`
- CLI: `watchtower sources list`, `watchtower collect --source <id>`

Collector credentials are read from Strongbox at run time; never commit them here.

---

Kestrel Technologies is a fictional company created for an educational workshop. Nothing in this repository is a real credential, person or product. Mirrored from Roost by `roost-mirror`; CL metadata is preserved in commit trailers (`Roost-CL:`, `Reviewed-by:`).
